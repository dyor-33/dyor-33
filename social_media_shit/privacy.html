Privacy Policy

Last updated: November 14, 2026

Geo Pipeline is a private tool used by a single person to upload educational videos to their own YouTube channel. This policy explains what it does with Google and YouTube data.

Who uses it

Only the channel owner. Geo Pipeline has no other users and offers no public sign-up.

What data it accesses

  • YouTube upload permission, used to upload videos to the owner's own channel.
  • Read-only YouTube access, used to read the owner's own channel and video statistics (such as views) to improve future videos.
  • Public YouTube data (titles, view counts, public comments on public videos), read through the YouTube Data API to study what topics and formats perform well.

It does not access any other person's private YouTube or Google account data.

How data is used and stored

Data is used only to publish and improve the owner's own videos. It is stored on a private server and a private database controlled by the owner. Login tokens are stored in a file readable only by the tool.

Sharing

Data is not sold, shared, or transferred to anyone. Content from public sources may be summarized by an AI service (Anthropic's Claude API) while preparing videos; no private Google user data is sent for advertising or any other purpose.

Google API Services

Geo Pipeline's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services and agrees to the YouTube Terms of Service. See also the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/connections. Stored tokens are deleted on request or when the tool is retired.
